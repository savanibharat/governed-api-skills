# 04 - Clarify
<!-- Ask only what the sources leave open. -->

Using `references/clarification-bank.md`, ask specific, answerable questions for every gap:
incomplete information, contradictions, or unknowns from stages 02 and 03. Do not ask about
things the docs already answer.

Confirm any inference you intend to rely on, promoting it from `inferred` to
`user-approved-assumption`.

Unattended: record each question as an open gap in the requirement's `open_question` and proceed
with the rest; surface them in the evaluation report. Do not invent answers.
