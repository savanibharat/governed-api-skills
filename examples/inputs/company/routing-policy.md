# Where to commit what (Acme routing policy)

- Generated skills go to the skills repo, under .claude/skills.
- Project evaluations and regression tests go to the skills repo.
- MCP usage/reference docs go to the MCP repo.
- Skill registrations, shared standards, and federated/canonical evals go to the governance repo.
- Anything written to the governance repo is a PROPOSAL and requires human approval.
